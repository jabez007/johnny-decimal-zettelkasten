# Johnny Decimal vault context

These terms distinguish note meaning, placement, and retrieval vocabulary.

## Language

**Community**:
A named knowledge grouping shared by related notes, potentially across systems. Community membership is independent of Johnny Decimal folder placement.
_Avoid_: Folder category, system membership

**Entity label**:
The exact name of a person, tool, organization, or concept represented in a note. Entity names remain extensible and can need disambiguation.

**Metadata catalogue**:
A vault-owned vocabulary of canonical communities, their meanings, and explicit synonyms.
_Avoid_: Entity registry, folder map

**Catalogue synonym**:
An explicitly approved alternate name for the same community. Historical notes can contain that name while new permanent notes use the canonical label.
_Avoid_: Note alias

**Note alias**:
An alternate title for one note, recorded in its frontmatter. It does not define a community synonym.

**Procedural rule**:
A scoped, evidence-backed claim about how an agent should work, recorded in AGNT. Domain knowledge belongs in the relevant permanent system.
